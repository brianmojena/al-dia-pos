05 · Preguntas

Antes de empezar.

¿Cómo instalo la app en Android?

Descarga el APK directo desde el enlace. Android puede pedirte permitir la instalación desde esa fuente; es el comportamiento normal para apps que no vienen de Google Play.

¿La app sirve para cobrar?

No. La app del dueño es para consultar: ventas del día, ganancia estimada, stock bajo y los ajustes de tasa y tope de transferencia. Las ventas se hacen en el sistema web o en la app de escritorio.

¿Qué pasa si se cae el internet?

La app de escritorio sigue vendiendo y sincroniza al volver la señal. El sistema web y la app del dueño necesitan conexión para mostrar los números actualizados.

¿Necesito una cuenta para probar?

No. Entra con demo@mitienda.cu y la contraseña demo1234. Es una cuenta compartida con datos de ejemplo.
