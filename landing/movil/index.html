Preguntas

Antes de empezar.

¿Cómo instalo la app en Android?

Descarga el APK directo. Android puede pedirte permitir la instalación desde esa fuente; es lo normal para apps que no vienen de Google Play.

¿La app sirve para cobrar?

No. Es para consultar ventas, ganancia, stock bajo y ajustes. Las ventas se hacen en el sistema web o en la app de escritorio.

¿Qué pasa si se cae el internet?

La app de escritorio sigue vendiendo y sincroniza al volver la señal. El sistema web y la app del dueño necesitan conexión.

¿Necesito una cuenta para probar?

No. Entra con demo@mitienda.cu y demo1234. Es una cuenta compartida con datos de ejemplo.
